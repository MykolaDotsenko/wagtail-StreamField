## Release gates

### Code quality

- Ruff lint passes.
- Ruff formatting passes.
- Django/Wagtail system checks pass.
- Migration drift is zero.
- Clean migrations apply.
- Global branch coverage threshold is enforced.

### Database confidence

The complete Django test suite runs against PostgreSQL 17 in CI in addition to the normal compatibility matrix.

This specifically protects behavior that SQLite can mask, including database constraints, transaction behavior and PostgreSQL-backed Wagtail search paths.

### Production configuration

CI verifies:

- `mysite.settings.production`;
- `manage.py check --deploy`;
- compressed manifest static collection through WhiteNoise;
- required production environment contract;
- secure cookie / HTTPS / referrer-policy settings;
- database-backed health/readiness behavior.

## What this evidence does not claim

The release does **not** claim:

- infinite-scale architecture;
- complete manual WCAG certification;
- production traffic/load testing;
- cloud-vendor-specific infrastructure;
- perfect semantic ingredient equivalence;
- AI-driven recommendations.

Those are deliberately outside the project scope until justified by a real product requirement.
